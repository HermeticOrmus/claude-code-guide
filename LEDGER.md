# Kintsugi ledger: claude-code-guide

Kintsugi mends a broken bowl with gold, so the repair is the part you look at. Here it means every crack we find in this guide and its starter kit is written down with its evidence, sealed with a fix you can check, and kept in this table instead of being patched quietly.

The hallmarked rows shipped in [v2.0.0](https://github.com/HermeticOrmus/claude-code-guide/releases/tag/v2.0.0), the second edition, through [#2](https://github.com/HermeticOrmus/claude-code-guide/pull/2), which was verified by installing the starter kit from GitHub into a clean config. For this ledger the released starter kit was installed from GitHub into a clean Claude Code config again: 1 of 1 enabled. The open row is a crack the repo tracks now; the Tracker column says where to pick it up.

Grades: **hairline** is copy or cosmetic, **fracture** is wrong behavior with a workaround, **break** means it did not work or broke a safety promise.
